# 우리 집 연금 찾기 (Streamlit 프로토타입)

HF 주택연금과 민간 역모기지 상품 9개를 대상으로, 질문에 답하면 상품별로
**가입할 수 있어요 / 확인이 필요해요 / 해당되지 않아요**를 판정해 주는 파이썬 웹앱입니다.

## 1. 내 컴퓨터에서 실행하기

파이썬 3.9 이상이 필요합니다.

```bash
cd jutaek-app
pip install -r requirements.txt
streamlit run app.py
```

브라우저가 자동으로 열립니다(기본 주소 http://localhost:8501).
같은 와이파이에 연결된 휴대폰에서는 터미널에 표시되는 `Network URL`로 접속하면 됩니다.

## 2. 인터넷에 올려서 링크로 공유하기 (무료)

1. GitHub에 저장소를 만들고 이 폴더의 파일을 모두 올립니다.
2. https://share.streamlit.io 에 GitHub 계정으로 로그인합니다.
3. **Create app** → 저장소 선택 → Main file path에 `app.py` 입력 → **Deploy**.
4. 몇 분 뒤 `https://<이름>.streamlit.app` 형태의 링크가 생깁니다. 심사위원과 팀원에게 이 링크를 공유하면 됩니다.

## 3. 폴더 구조

```
jutaek-app/
├── app.py               화면 (질문 1개씩, '잘 모르겠어요' 안내, 결과, 관리자 화면)
├── engine.py            추천 Rule 엔진 (화면과 분리, 따로 테스트 가능)
├── data/
│   ├── products.json    상품 DB: 상품별 가입 조건, 판매 상태, 마지막 확인일, 출처
│   └── questions.json   질문 DB: 질문 문구, 선택지, 보여주는 조건, 확인 경로 링크
├── tests/test_engine.py 예시 인물 4명으로 판정 결과 검증
└── requirements.txt
```

## 4. 상품 조건이 바뀌었을 때 (기획서 9·10번과 연결)

화면 코드는 건드리지 않고 `data/products.json`만 고칩니다.

- **판매 중단**: `"sale_status": "판매 중"`을 `"확인 필요"`로 바꾸면 그 상품은 '가입할 수 있어요'에 나오지 않습니다.
- **조건 변경**: 예를 들어 HF 주택가격 기준이 바뀌면 `groups.hf_base`의 해당 조건 값만 고칩니다.
- **선택지 추가**: 새 선택지가 필요하면 `data/questions.json`의 `options`에 추가하고,
  `products.json`에서 그 값을 `check_values`(확인 필요) 등에 넣습니다.
  (예: 2026년 실거주 예외 → Q5에 `tmp` 선택지, HF 조건에 `"check_values": ["tmp"]`)

어떤 질문이 어떤 상품 판정에 쓰이는지는 앱의 **상품 DB (관리자)** 화면 → **질문 변경 영향도** 표에서 볼 수 있습니다.

### 조건 작성 형식

```json
{"label": "부부 중 한 분이 만 55세 이상",
 "cond": {"field": "age_older", "op": ">=", "value": 55}}
```

- `field`: 질문 id(`houses`, `price`, `type` …) 또는 나이 값(`age_self`, `age_older`, `age_younger`)
- `op`: `in`(목록 중 하나), `>=`, `<=`, `between`([최소, 최대])
- `check_values`: 이 답이면 '확인 필요'로 판정 (`check_label`이 안내 문구)
- `otherwise`: 조건을 못 맞췄을 때 예외 규칙 (예: 12억 초과 2주택 → 처분 조건부 '확인 필요')

## 5. 테스트

```bash
python tests/test_engine.py
```

## 6. 판정 규칙 요약

| 결과 | 기준 |
|---|---|
| 가입할 수 있어요 | 모든 조건 충족 + 판매 중 |
| 확인이 필요해요 | '잘 모르겠어요'로 넘긴 조건이 있거나, 증빙·예외 확인이 필요하거나, 판매 여부 미확인 |
| 해당되지 않아요 | 조건 하나라도 불충족 (이유를 함께 표시) |

같은 결과 안에서는 Q11에서 고른 지급 방식(평생/기간)과 맞는 상품을 위로 올립니다.

> 이 서비스는 입력한 조건에 해당하는 상품 정보를 안내할 뿐, 특정 상품의 가입을 권유하지 않습니다.
> 상품 조건은 2026년 10월 조사 기준이며, 실제 가입 가능 여부는 각 금융회사에서 확인해야 합니다.
